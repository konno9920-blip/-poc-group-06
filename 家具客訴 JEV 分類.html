接軌教學
JEV 分類題目（可複製）
請閱讀家具客訴內容，只依照內容選擇最適合的客訴類別。可選：安全疑慮、外觀瑕疵、木材瑕疵、五金／組裝、尺寸／規格、顏色／材質、運輸損壞、交期／缺件、氣味／環保、其他／待人工判定。若資訊不足，選「其他／待人工判定」。不要自行補充沒有出現的事實。

本頁沒有 JEV API 金鑰欄位。正式串接應由後端保管 API 金鑰，避免把金鑰寫進可公開檢視的 HTML。

CSV 欄位格式與匯入方式

最推薦的欄位：案件編號、客戶、家具品項、客訴內容、客訴類別、緊急程度、負責部門、狀態。

也接受常見英文欄名如 id、text、predicted、priority、department。未知類別會標示待人工判定。

匯入只讀取檔案，不會自動呼叫 JEV。分類欄位若來自 JEV 才表示模型輸出；請先由人工確認。

若要測試匯入：按「下載 CSV 範本」，在 Excel 填寫或貼入 JEV 分類結果後存成 CSV，再點「匯入」。
