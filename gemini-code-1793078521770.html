Consumer Complaint Text Classification

專案概述

將消費者申訴資料集 (Consumer Complaint Database)[cite: 1] 進行文字分類，分為以下類別[cite: 1]：

  • 0: Credit reporting, repair, or other[cite: 1]
  • 1: Debt collection[cite: 1]
  • 2: Consumer Loan[cite: 1]
  • 3: Mortgage[cite: 1]

5. Model Building and Evaluation

models = [ RandomForestClassifier(n_estimators=100, max_depth=5, random_state=0), LinearSVC(), MultinomialNB(), LogisticRegression(random_state=0, max_iter=1000) ] CV = 5 cv_df = pd.DataFrame(index=range(CV * len(models))) entries = [] for model in models: model_name = model.__class__.__name__ accuracies = cross_val_score(model, features, labels, scoring='accuracy', cv=CV) for fold_idx, accuracy in enumerate(accuracies): entries.append((model_name, fold_idx, accuracy)) cv_df = pd.DataFrame(entries, columns=['model_name', 'fold_idx', 'accuracy'])
mean_accuracy = cv_df.groupby('model_name').accuracy.mean() std_accuracy = cv_df.groupby('model_name').accuracy.std() acc = pd.concat([mean_accuracy, std_accuracy], axis= 1,ignore_index=True) acc.columns = ['Mean Accuracy', 'Standard deviation'] acc
